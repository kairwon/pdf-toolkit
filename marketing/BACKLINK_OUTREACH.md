## Directory profile copy

Name: Lab of PDF

Tagline: Private PDF tools for real document requirements

Short description:

Lab of PDF is a free, open-source PDF toolkit that runs document processing locally in the browser. Users can merge, split, compress, convert, watermark, and visually manage pages without uploading the PDF or creating an account.

Long description:

Lab of PDF starts with practical outcomes such as meeting a university upload limit, preparing a visa document pack, or fixing page order before submission. Supported workflows run on the user's device. The project publishes its security model, editorial process, practical guides, and a printable PDF submission checklist. The source is available on GitHub under the MIT license.

Suggested categories: PDF tools; document management; office productivity; privacy; local-first; open source; student tools.

## Product Hunt draft

Tagline: Meet the PDF requirement without uploading the document

First comment:

I built Lab of PDF because most people do not want a “compression level”—they need a university, visa, government, or client portal to accept the final document. The tools run locally in the browser, require no account, and now include visual page management, exact-size workflows, OCR, practical guides, and a printable submission checklist. I would especially value feedback on which real submission workflow still feels confusing.

Do not ask people to upvote. Ask relevant users to try a workflow and leave honest feedback.
